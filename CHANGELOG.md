# Changelog

All notable OverloadKit / factory changes land here.

## 0.2.0 — 2026-09-14

### OverloadKit

- Expand `Mass` with pounds initializer, `Comparable`, and fixed-point `formatted(unit:)`
- Add `MeasurementFormatting`, `LayoutSpacing`, `KeyValueStore` (+ in-memory + UserDefaults), `KitLog`
- Bump `OverloadKit.version` to `0.2.0`

### Factory

- TemplateApp demos kit spacing, mass formatting, and launch logging
- Scaffolded apps now include `.gitignore`, SwiftLint, and consumer CI
- Consumer CI can authenticate to a private kit via `OVERLOADKIT_TOKEN`
- Add `ROADMAP.md` for the first real consumer app decision
